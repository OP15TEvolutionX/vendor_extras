# One-off verification scripts

Preserved for the history of fairlady bring-up. These scripts assume the original
/home/ivan/evolutionX checkout and particular grid/padding values or target-files
staging. They are not generally runnable after final OTA packaging removes staging.
check-apk-duplicates.py is superseded by the tested, integrated checker at
vendor/lineage/build/tools/check_apk_packages.py, which also handles valid split APKs.
